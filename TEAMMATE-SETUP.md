# Teammate Setup Guide

Welcome to the website project. This is a one-time setup that takes about 20 minutes.
Most of the technical work is handled for you by a tool called Claude Code, so don't
worry if any of this looks unfamiliar. Just follow the steps in order.

If you get stuck on any step, send Jake a screenshot and he'll help, or you can hop on
a quick call.

---

## What you'll need first

- A Mac.
- A paid Claude plan (Pro, Max, or Team). Claude Code does not work on a free account.
  If you're not sure, ask Jake, he may add you to the company Team plan.

---

## Step 1 — Create a free GitHub account

GitHub is where the website project lives. If you don't already have an account:

1. Go to https://github.com
2. Sign up.
3. Reply to Jake with your **GitHub username** so he can add you to the project.

## Step 2 — Accept the invite

Once Jake adds you, GitHub emails you an invitation to the project.
Open it and click **Accept**. This gives you the same access Jake has.

## Step 3 — Install Claude Code

Claude Code is the tool used to build and edit the pages.

1. Download it from https://claude.com/download
2. Install it like any other Mac app and open it.
3. Sign in with your paid Claude account.

(Setup help, if you want it: https://code.claude.com/docs/en/desktop-quickstart)

## Step 4 — Log in to GitHub as yourself

When Claude Code asks you to connect to GitHub, log in with **your own** GitHub account,
not Jake's. This just makes sure our changes are labeled correctly so we can always see
who did what.

## Step 5 — Get the project onto your computer

Open Claude Code and paste it this exact request:

> Clone github.com/Jake-YYZ/consultus-site-prototypes and set it up so I can preview it locally.

Claude Code will pull down the whole project and get you ready to go. When it's done,
you'll be able to see the site in your browser and start editing.

---

## How we work together day to day

This keeps us from stepping on each other. It's light:

1. **Start of your work session:** tell Claude Code
   *"pull the latest from GitHub first."*
   This grabs whatever Jake changed so you're building on the newest version.

2. **When you're done:** tell Claude Code
   *"push my changes."*
   This sends your work up and it goes live automatically.

3. **We'll loosely split up the pages** so we're rarely editing the same file at the
   same time. Jake will sort that out with you once you're set up.

That's everything. Welcome aboard.
